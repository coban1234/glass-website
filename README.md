# Northlight Glass

Metro Vancouver glass & glazing site. Design direction: **Headline** (v4.0 Cold Glass, Warm Room).

Live: https://coban1234.github.io/glass-website/

Brand name, phone, prices, insurance, and photography are placeholders until the client confirms them.

```
npm install
npm run dev
```

Astro + Tailwind. Interactive pieces are small client scripts: defog compare (INT-1) and the sealed-unit explainer (INT-3).
